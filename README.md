Learning Summary:

Squash allows you to consolidate multiple commits into one, but does not commit them. I would use this if I made multiple small commits for logging purposes and then wanted to group them up for cleanliness at the end of the project or task.

Cherry-pick lets you take one commit from any branch and apply it to your own. I would use this if experimenting on a branch and wanting to introduce a specific commit to my main.

Merge brings another branch into your own with all of its commits. I would use this when working on a project with others, and we're integrating our work.

Rebase allows you to apply the commits from another branch to your own so you can have a cleaner work history. I would rebase if I wanted to merge branches while maintaining a clean, linear commit history.
