Learning Summary:

Squash allows you to make a consolodate multiple commits into one, but does not commit them.

Cherry-pick lets you take one commit from any branch and apply it to your own.

Merge brings another branch into your own with all of its commits.

Rebase allows you to apply the commits from another branhc to your own so you can have a cleaner work history
